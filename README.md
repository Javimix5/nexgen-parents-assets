# Assets

Repositorio de **activos e imágenes** utilizados en la plataforma [NexGen Parents](https://nexgenparents.com): guías de control parental para familias.

## ¿Qué contiene este repositorio?

- Imágenes y gráficos empleados en la interfaz de la plataforma.
- Iconos, logotipos y banners oficiales.
- Ilustraciones y material visual para documentación y marketing de NexGen Parents.
- Archivos estáticos que enriquecen la experiencia del usuario.

## Estructura de carpetas

```
/
├── control-parental/
├── forum/
├── icons/
├── info/
├── video/
```

## Uso de los activos

- **Uso autorizado:** Las imágenes están destinadas exclusivamente para la plataforma y documentación oficial de NexGen Parents.
- **Créditos:** Si necesitas usar algún material gráfico fuera del entorno oficial, solicita autorización o cita la fuente apropiadamente.
